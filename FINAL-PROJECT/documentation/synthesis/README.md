# Synthesis and Gate-Level Artifacts

This folder contains the Yosys netlist and logs retained from the project run.

- pill_reminder_netlist.v: synthesized netlist used as the gate-level design source.
- pill_reminder_gls.v: gate-level netlist supplied with the project.
- yosys.log: synthesis tool log.
- gls_synthesis.log: gate-level preparation and synthesis log.

The RTL and testbenches are in the project-level src and tb directories. Simulation outputs and the VCD waveform are in simulation.
